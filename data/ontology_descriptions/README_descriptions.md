# Описания узлов ГРНТИ для классификатора

Два датасета с LLM-сгенерированными описаниями листовых узлов ГРНТИ.
Описания нужны для использования в качестве **якорей узлов** при retrieval-классификации текстов на коды ГРНТИ.

## Файлы

| Файл | Источник | Покрытие листьев | Средняя длина |
|---|---|---|---|
| `grnti_descriptions_yagpt.parquet` (или `.csv`) | YandexGPT-235B v2 | 7047 / 7150 | ~860 символов |
| `grnti_descriptions_gigachat.parquet` (или `.csv`) | GigaChat-702B v6_optimized | 7023 / 7150 | ~1150 символов |

YaGPT даёт полное покрытие, GigaChat — частичное (можно использовать как дополнение или альтернативу).

## Схема

| Колонка | Тип | Описание |
|---|---|---|
| `node_id` | str | URI узла онтологии (`http://example.org/competencies#GRNTI_XX_YY_ZZ`) |
| `code` | str | Код ГРНТИ в формате `XX.YY.ZZ` |
| `label` | str | Название листа (например, «Астрофизика») |
| `full_label` | str | Полная цепочка от корня (например, «Естественные науки → Астрономия → Астрофизика») |
| `depth` | int | Глубина в дереве (3 для листьев) |
| `ontology_description` | str | Оригинальное определение из `ontology_grnti.json` (до LLM) |
| `llm_description` | str | **Главное поле**: LLM-описание узла |
| `llm_model` | str | Имя модели-генератора |

## Как использовать в классификаторе

Для каждого листа `node_id` собирается множество якорей $\mathcal{Y}_v$:
- метка узла (`label`)
- полное название (`full_label`)
- определение из онтологии (`ontology_description`)
- **LLM-описание** (`llm_description`) — добавляется отсюда

Тексты из этого датасета прогоняются через ваш bi-encoder, эмбеддинги складываются в FAISS-индекс по узлу. На инференсе сходство по узлу вычисляется как **max** по всем якорям:
$$ \text{sim}(x, v) = \max_{y \in \mathcal{Y}_v} \cos(E(x), E(y)) $$

Это multi-anchor max-pool. Если у узла больше одного описания (например, и YaGPT, и GigaChat), оба добавляются как отдельные якоря — это даёт ансамбль стилей без явного выбора одного из них.

## Контрольный пример

```python
import pandas as pd

ya = pd.read_parquet('grnti_descriptions_yagpt.parquet')
print(ya.iloc[0]['code'], '|', ya.iloc[0]['label'])
print(ya.iloc[0]['llm_description'][:200])
```

## Примечания

- Описания сгенерированы при temperature=0.3 (умеренная вариативность, стиль научной аннотации).
- Промпт v2 (plain natural language) выбран по результатам грид-сёрча: формальные форматы (JSON/YAML/Markdown) ухудшают качество для retrieval-задачи на 35–61 %.
- На холодных листьях (мало или нет реальных размеченных примеров в gisnauka) LLM-описания дают наибольший прирост качества классификации (+21 % round-trip Recall@1 в нашем эксперименте).
- Все описания на русском языке, в стиле научного дискурса с упоминанием ключевых методов и предметных областей.
